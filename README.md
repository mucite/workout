# Recomp · Phase 1

Workout + meal plan web app (static, no build step). Progress is saved in your browser.

## Deploy to GitHub Pages
1. Create a new public repo on GitHub (e.g. `recomp`).
2. Upload every file in this folder to the repo root (Add file → Upload files).
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. After ~1 minute it's live at `https://<your-username>.github.io/recomp/`.

On your phone: open the link → Share → "Add to Home Screen" to use it like an app.
